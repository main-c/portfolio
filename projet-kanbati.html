Kanbati

Site management for construction firms, on web and mobile.

Visit website
Client
Construction firms
Role
Front-end developer
Platform
Web, mobile
Code
Private, client project

Context

A site-management platform for construction firms, covering tasks, attendance, inventory, finances, and documents, designed for teams working in the field.

What I did

  • Set up the front-end architecture of the application.
  • Designed and built modern, responsive, and reusable web interfaces with React.
  • Built a consistent interface with shadcn/ui and the React ecosystem.
  • Integrated the REST APIs and managed data exchange with the back-end services.
  • Optimized the web app for search engines (SEO).
  • Structured the front-end code so the app stays easy to maintain and extend.
  • Worked with the back-end and product teams to turn requirements into working interfaces.

  • REST APIs
